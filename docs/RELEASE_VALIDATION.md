# v0.9.3の検証範囲

2026-10-28時点の公開準備で確認した内容です。v0.9.2の検証結果に、既存SAMの一時ログインと直接API経路の検証を追加しました。

## ローカル自動テスト

macOS / QGIS 3.44.8のPythonで100件成功。認証APIとクラウド通信はテスト用アダプターで置き換えています。

- 形式変換、時刻基準、日付境界、無効な記録の保持
- 複数SIMの分離、取得範囲の分割、ページング、キャンセル
- 設定変更の自動反映、失敗時の保持、修正後の再試行
- カメラの対応、静止画・動画の要求、キャッシュ、再読込
- 認証の権限確認、キーの発行状態、不明な作成要求の再送抑止
- フッター背景、スクロール境界、名前フィルター、設定ダイアログ

開発中の別のオフスクリーン実行で終了コード139の停止を1回観測しています。診断付きの再実行と今回の公開準備での全件実行は成功しましたが、最初の停止原因は未特定です。

## 実環境での確認

開発過程で、macOSのQGISからCLI経由でHarvestの実データを読み込み、点クリックからソラカメの静止画・10秒動画の新規取得、キャッシュ再利用、動画再生を確認しました。GeoPackage保存と再読込も確認しています。v0.9.2更新時には位置レイヤ、カメラ設定、表示範囲の保持と固定フッターの文字重なり解消を確認しました。

## 未検証

- Windows・LinuxのGUI、QGIS 4
- GPSマルチユニット／ビーコン対応GPSトラッカーGW実機からの送信を含む一貫検証
- 全認証方式についての実アカウントでの一貫検証
- GNSSの絶対精度、カメラ録画との厳密な同期精度
- 別PCへ移したキャッシュの自動再接続

GitHub ActionsはQGISを必要としないテストと配布ZIPの構造検査を実行します。GUI統合テストはQGISがない環境ではスキップされるため、CI成功だけでGUIや各OSの対応を示すものではありません。

## v0.9.3の追加検証（2026-10-28）

既存SAMでの一時ログインを追加した後、macOS / QGISの自動テスト100件が成功しました。CLI呼び出しを禁止した実QGISで、日本・グローバルのSIM一覧、2台のトラッカーのHarvestインポート、点クリックによるソラカメ動画の新規取得・内蔵再生を確認しています。ログアウト後のAPI拒否、通常終了時の両カバレッジのログアウト、再起動後の再ログイン要求も確認済みです。詳細は[認証と権限](AUTHENTICATION.md#検証範囲)を参照してください。
